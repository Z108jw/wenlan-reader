# 文澜 · 文献批注工作台

一个完全运行在浏览器本地的英文文献阅读、翻译与批注工具。上传 PDF 后自动解析标题、摘要、正文与章节结构，在左右分栏中完成逐句翻译、重点标记、批注与导出。所有解析和保存都在本机完成，不需要服务器，也不依赖外部 CDN。

## 功能

- **PDF 本地解析**：内置 PDF.js，离线提取文字并重建标题、作者、摘要、关键词与章节层级。
- **只读到结论**：自动在 `6. Conclusion` 结束后截断，不读取参考文献、附录与后置事项。
- **左右分栏阅读**：左侧为排版后的英文原文，右侧为可拖动调宽的批注区。
- **全内容批注**：论文标题、作者、来源、关键词、各级标题、摘要、正文与图表题注都可标记和批注。
- **任意范围标记**：支持点击整句，也支持拖选任意文字、跨句或跨段批注。
- **翻译**：逐句翻译，支持摘要、已批注句子和正文全文；可配置兼容 OpenAI 的接口或本地 Ollama。
- **图表原页**：图表题注自动嵌入原页截图，可点击放大；顶部“原页”模式可查看完整 PDF 页面。
- **目录与定位**：左侧目录支持多级标题跳转，滚动时自动跟随；右侧批注随阅读位置联动。
- **文献库管理**：新建、重命名、删除文献夹，拖拽移动文献，单独删除文献，修改文献显示名称。
- **独立 HTML 导出**：导出的批注版 HTML 内嵌原文、译文、批注、标签、目录和图表原页，可离线打开、继续编辑与再次导出。
- **原地重新解析**：已批注的文献可重新解析 PDF，批注、译文和标签会自动重新定位，不需要重新上传为新文献。
- **自动保存**：普通版保存在本地浏览器；导出的 HTML 同时内嵌数据快照。

## 使用

1. 下载或克隆仓库。
2. 双击打开 `index.html`，推荐使用 Chrome / Edge。
3. 上传 PDF，或点击“先看看示例文献”体验完整流程。
4. 在批注区写译文与批注，点击右上角“下载批注版”导出独立 HTML。

不需要安装依赖，也不需要启动本地服务。

## 开发

源码在 `src/`，构建脚本会把样式、演示文献、PDF.js 引擎与应用代码打包成一个独立的 `index.html`：

```bash
python build.py
```

构建结果约 2 MB，包含离线 PDF 解析引擎。

## 目录

```text
index.html          构建后的单文件应用，直接打开即可
src/app.js          应用逻辑
src/styles.css      界面样式
src/demo.js         内置示例文献与译文
src/template.html   单文件模板
build.py            构建脚本
```

## 说明

- PDF 文件不会被上传到任何服务器。
- 上传后的 PDF 会缓存在浏览器本地，之后重新解析不需要再次选择文件；清除浏览器数据后需要重新选择原 PDF。
- 默认免费翻译接口可能需要网络；也可在“翻译设置”中配置自己的大模型 API。
- 导出的批注版 HTML 体积会因 PDF 页数和原页图片而增加，通常在数 MB 左右。
